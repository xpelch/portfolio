# Competitive Benchmark

Product idea: Portfolio moderne, representatif et professionnel, cozy, avec quelques easter eggs et effets wow discrets. Objectif: polish produit comparable au GAFAM, zero friction, navigation evidente, workflows fluides, etats UI complets, performance percue rapide, accessibilite propre, qualite technique verifiee, en conservant le design actuel.
Workspace: portfolio
Context: fullstack
Target: BUILD A BILINGUAL DEVELOPER PORTFOLIO THAT MAKES XAVIER PELCHAT FEEL LIKE A

## Reference Bar
- Apple: clarity, restraint, perceived quality, coherent interaction details.
- Microsoft: admin depth, enterprise trust, predictable controls, supportable operations.
- Google: speed, searchability, forgiving flows, readable information architecture.
- Meta: fast feedback, social/product loops, scalable surface design.
- TikTok: low-friction creation/consumption loop, immediate momentum, strong mobile ergonomics.

## Benchmark Criteria
- Friction: number of decisions, fields, waits, dead ends, and context switches before success.
- Speed: first meaningful paint, interaction latency, search/filter response, publish time.
- Clarity: visible hierarchy, action naming, state language, form guidance, recovery copy.
- Trust: permissions, confirmations, auditability, error quality, privacy posture.
- Onboarding: time to understand value, start, complete, and repeat.
- Visual density: public surface feels premium; admin surface supports scanning and repeated work.

## Score Method
- Compare the primary journey and admin publish flow against the references above.
- Attach proof: screenshots, recordings, timings, event funnels, support tickets, and error logs.
- Treat any missing proof as a cap, not as neutral evidence.
